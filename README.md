# Weather Prediction Dashboard

## Призначення проєкту

Цей проєкт призначений для прогнозування опадів у населених пунктах України.
Застосунок завантажує історичні погодні дані з Open-Meteo, формує датасет,
навчає кілька моделей машинного навчання та прогнозує, чи очікуються опади
на найближчі дні.

Інтерфейс реалізовано за допомогою Streamlit.

## Які дані використовуються

Користувач вводить населений пункт України. Координати визначаються автоматично
через Open-Meteo Geocoding API. Після цього історичні погодні дані
завантажуються через Open-Meteo Archive API.

Використовуються такі метеодані:

- максимальна температура;
- мінімальна температура;
- швидкість вітру;
- сума опадів.

Цільова змінна формується так:

```python
target = precipitation_sum > 0
```

`precipitation_sum` використовується тільки для створення цільової змінної.
Вона не використовується як ознака моделі, щоб уникнути витоку даних.

Файл з початковими даними:

```text
weather_daily.csv
```

## Попередня обробка даних

Перед навчанням дані діляться на train/test. Пропущені значення в ознаках
заповнюються median-значеннями, розрахованими тільки на навчальній вибірці.
Ті самі значення використовуються для test-частини та майбутнього прогнозу.

Також враховано можливий дисбаланс класів:

- показується розподіл класів;
- у моделях використовується `class_weight="balanced"`;
- якщо в даних є тільки один клас, застосунок просить збільшити період.

## Feature selection

Фінальний набір ознак формується не випадково, а за допомогою `SelectKBest`.

Кандидатні ознаки:

- `temperature_max`
- `temperature_min`
- `wind_speed`
- `temperature_avg`
- `temperature_range`
- `wind_temp_ratio`

Після відбору моделі навчаються тільки на найкращих ознаках.

## Які моделі використовуються

У проєкті навчаються та порівнюються такі моделі класифікації:

- Logistic Regression
- Decision Tree
- Random Forest

Якість моделей оцінюється за метриками:

- Accuracy
- Precision
- Recall
- F1-score

Фінальна модель вибирається за найкращим F1-score і зберігається у файл:

```text
models/rain_model.pkl
```

## Що робить кожен файл

`app.py`  
Головний Streamlit-застосунок. Містить інтерфейс, вибір населеного пункту,
завантаження даних, графіки, таблиці, навчання моделей і прогноз.

`data_loader.py`  
Працює з Open-Meteo API. Шукає населений пункт України, отримує координати,
завантажує історичні погодні дані та зберігає `weather_daily.csv`.

`train_model.py`  
Формує target, створює ознаки, виконує preprocessing, feature selection,
навчає кілька моделей, порівнює метрики та зберігає фінальну модель.

`predict.py`  
Завантажує збережену модель, отримує прогноз погоди на найближчі дні та
прогнозує ймовірність опадів.

`requirements.txt`  
Містить список бібліотек, потрібних для запуску проєкту.

`weather_daily.csv`  
Файл з історичними погодними даними, які використовуються для навчання.

`models/rain_model.pkl`  
Збережена фінальна модель.

## Послідовність роботи застосунку

1. Користувач вводить населений пункт України.
2. Застосунок знаходить координати через Open-Meteo Geocoding API.
3. Завантажуються історичні погодні дані.
4. Дані зберігаються у `weather_daily.csv`.
5. Формується цільова змінна `target`.
6. Виконується попередня обробка даних.
7. Виконується feature selection.
8. Навчаються кілька моделей класифікації.
9. Моделі порівнюються за метриками.
10. Найкраща модель зберігається.
11. Для найближчих днів завантажується прогноз погоди.
12. Збережена модель прогнозує ймовірність опадів.

## Запуск проєкту

У терміналі потрібно перейти в папку проєкту:

```powershell
cd "C:\Users\HOME\OneDrive\Робочий стіл\weather-rain-prediction"
```

Встановити бібліотеки:

```powershell
python -m pip install -r requirements.txt
```

Запустити Streamlit:

```powershell
python -m streamlit run app.py
```

Після запуску застосунок відкриється у браузері за адресою:

```text
http://localhost:8501
```
